# GGPlan

GGPlan（Game Scheduler）幫同時玩多款遊戲的玩家規劃每日、每週行程。這個 repo 只放安裝檔與更新檔；程式碼不公開。

## 安裝

1. 到 [Releases](https://github.com/Miku4364/GGPlan-releases/releases/latest) 下載 `GGPlanApp-win-Setup.exe`。
2. 第一次執行時，Windows 可能顯示「Windows 已保護您的電腦」（試用階段的安裝檔沒有數位簽章）：
   1. 點「其他資訊」。
   2. 確認檔名是 `GGPlanApp-win-Setup.exe`，按「仍要執行」。
3. 安裝完成後會自動開啟 GGPlan，並在開始功能表與桌面建立捷徑。

需要 Windows 10（1809）以上的 64 位元版本。

## 更新

GGPlan 會在背景下載新版，下次啟動時自動套用；也可以在「設定 → 版本與更新」手動檢查。

## 解除安裝

Windows 設定 → 應用程式 → GGPlan → 解除安裝。你的資料（`%LOCALAPPDATA%\GGPlan`）不會被刪除，重新安裝後仍在。
